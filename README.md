# 📊 AI Data Analyst

An AI-powered data analysis assistant that transforms raw CSV and Excel datasets into interactive dashboards, useful insights, and natural-language answers.

The application combines AI reasoning with Python-based data processing so that AI can help plan and explain the analysis while Python performs the actual dataset calculations and validation.

---

## 🚀 What It Does

AI Data Analyst allows users to upload a CSV or XLSX file and automatically explore the dataset without writing code.

### Core capabilities

- 📂 CSV and XLSX upload
- 🔎 Automatic dataset profiling
- 📊 AI-generated dashboards
- 📈 Interactive Plotly visualizations
- 💡 AI-generated insights
- 💬 Natural-language dataset Q&A
- 🧮 Python-based calculations
- 🛡️ Validation of AI-generated analysis
- 📋 Numerical summaries
- 🔍 Missing-value and duplicate detection
- 🧠 Automatic detection of numeric, categorical, date, identifier, and text columns

---

## 💡 Problem

Working with raw datasets often requires knowledge of Python, SQL, statistics, and visualization tools.

For beginners, students, small teams, and non-technical users, turning a CSV file into meaningful analysis can be time-consuming.

AI Data Analyst aims to reduce that barrier by providing an interactive workflow from:

**Raw Dataset → Analysis → Visualization → Insights → Questions**
