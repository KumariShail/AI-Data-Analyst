# 🤖 AI Data Analyst — Snapdragon Edition

An AI-powered data analysis application that transforms raw CSV/XLSX datasets into interactive dashboards, automated insights, and natural-language answers.

Built for the **Snapdragon® AI Lab Build & Present Challenge** with a focus on making data analysis faster, simpler, and more accessible.

---

## 🚀 What It Does

AI Data Analyst allows users to upload a dataset and automatically explore it without manually writing SQL queries or creating charts.

```text

        ↓
